## 수정 및 검토

- 구현 전 기준 테스트: 96개 중 TODO/미구현 API 관련 95개 실패를 확인했다.
- H2의 따옴표 처리에 맞추어 @Table과 실제 테이블의 대소문자를 일치시켰다.
- Unicode 공백 입력과 코루틴 실제 시작·취소·finally 정리의 회귀 테스트 실패를 확인한 뒤 수정했다.
- JavaCaller를 두 학습 패키지별로 두어 각자의 KotlinBridge를 호출하도록 했다.
- 기본 test의 exercise 제외 설정을 해당 작업에만 적용하여 exerciseTest가 독립 실행되도록 했다.
- 별도 읽기 전용 코드 검토에서 발견한 기능상 문제를 반영했다. 추가 검토를 반복하는 대신 전체 테스트와 실제 HTTP를 검증했다.
- 테스트 실행 시 JDK에서 bootstrap classpath 관련 경고가 출력된다. 테스트 실패나 Kotlin 컴파일 오류는 없다.

## 범위와 선택

- 지정된 빈 디렉터리에 구현했고 Git 초기화·커밋·worktree 생성은 수행하지 않았다.
- 메모리 H2를 사용하므로 재시작하면 학습 기록이 초기화된다.
- 취소 예제는 시작·취소·정리 여부 3개를 순서대로 반환하여 실행 흐름을 관찰한다.
- 언어의 모든 조합과 표준 라이브러리 전체가 아닌 JVM 안정 기능의 주요 범주를 학습한다.
- 인증·배포·동시 수정 충돌 정책·preview 및 멀티플랫폼 기능은 승인된 학습 범위 밖이다.

자세한 문법 범위와 제외 항목은 [COVERAGE.md](COVERAGE.md)를 참고한다.
